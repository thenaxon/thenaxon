## 🐨 [somora](https://github.com/thenaxon/somora_agent) — your AI team, on your own machine

Personal AI agents that work together, share one memory and keep learning
while they sleep.

- **Any model, mid-conversation**: Claude, ChatGPT, Grok or your own local models.
- **Shared memory**: what the agents learn becomes a long-term wiki, built while they "dream".
- **A real team**: agents ask each other, hand work over, run tmux sessions and a browser.
- **Everywhere**: web desktop, terminal, phone, and voice calls.

```bash
curl -fsSL https://somora.ai/install.sh | bash
```

## 🎙️ [somora_realtimevoice](https://github.com/thenaxon/somora_realtimevoice) — call your agents, on your own models

A voice server that speaks the OpenAI Realtime protocol, so somora's voice
calls run on your own speech recognition, language model and speech output
instead of a cloud API.

- **Clone a voice** from a 10-second recording, or use a model's built-in voices.
- **Any OpenAI-style model server**: a local one such as mlx-audio, a cloud API, or a router in front of several.
- **Natural calls**: interrupt it any time; a small speech model on the CPU keeps coughs and noise out.
- **No GPU needed** for the server itself: Docker or a plain Python service.
